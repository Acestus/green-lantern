3. Architectural Principles

API-first rendering: the SWA reads through function APIs instead of directly embedding storage credentials.
Cost-aware hosting: Flex Consumption keeps serverless economics for non-constant traffic.
Identity-based access: UMI is the standard for secure service-to-service access.
